凭据安全模型

为什么 id 既是路由也是密码
▸ 创建后仅返回 1 次明文 key（kev_xxxx...），随后只显示 id（8a3f...）。
▸ 浏览器调 /console/api/kev/* 时，把 id 当 Bearer 提交：Authorization: Bearer 8a3f2e1c9b4d...
▸ 服务端按 id 查表，存在且 active 即放行。前端永不接触任何 64 字符的明文密钥。
▸ 撤销 = 软删（active=0），可恢复；硬删 = 物理删除，永久。
