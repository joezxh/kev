「算子指一次不可再分的张量计算单元：给定输入张量，执行一段固定的数学运算，产出输出张量。」 —— 本页把这句话拆成四张可以播放的动图。

1. 张量是什么 静态示意

张量（tensor）说穿了就是「形状固定的多维数字数组」： 先规定它是几层嵌套（shape），再往里填数。数一个嵌套层级，就是它的「阶」。

在 Kev 里：一批问题的 token id 是 2 阶张量 (batch, seq)， 模型内部的隐藏状态是 3 阶张量 (batch, seq, hidden_dim)。

4. 稍复杂一点：矩阵乘法（GEMM） 动图

真实 LLM 里最重的算子就是矩阵乘法（GEMM）：注意力的 QKᵀ、加权求和、FFN、各种投影全是它。 规则只有一句 —— C 的第 i 行 j 列 = A 的第 i 行 · B 的第 j 列（点积：对应位置相乘，再全部加起来）。 它吃两个输入张量、吐一个输出张量，但依然是一个不可再分的算子。

5. 常见 LLM 算子表 · 与 Kev / Jev 对比 静态表

横向是「一个生成式 LLM 推理栈里会碰到的算子」，纵向三个维度：存在性与替代（常见 LLM / Kev / Jev 各列）、产出指标、计算·访存开销。 核心结论：Kev 是 prefill-only 决策模型，砍掉了整个「词表投影 + 采样解码 + 自回归循环」，换成一个指针读出； Jev 是完整生成式决策系统，保留全套解码算子 —— 但它在本仓库是 API 黑盒（经 Vercel AI Gateway，由 kev.jev 打分），算子内部不可见，指标是端到端的 JevBench 决策准确率而非逐 kernel。
