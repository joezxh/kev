- 模型差异通过参数化而非分支逻辑实现：脚本根据 -Model 选择对应的 docker-compose-<model>.yml、Dockerfile.<model>、默认 runs/<name> 与 HF Hub id。
- 环境变量一律以 ${VAR:-默认值} 形式在 compose 中透传，允许 shell 或 .env 覆盖，避免硬编码运行时配置。
- 部署脚本在执行 docker compose down/up 时包裹于 cmd /c "... >nul 2>&1"，绕过 PS5.1 $ErrorActionPreference=Stop 对原生命令 stderr 的终止行为。
- 启动后通过轮询 HTTP 健康端点（/v1/models 与 /）等待服务就绪，而非仅依赖容器 healthy 状态。
