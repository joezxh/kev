- 每个 evals 子面板都包含一个 `manifest.json`，记录 version、seed、dataset/base revisions、context 限制、各文件 sha256+record/question 计数以及 admission/code_hashes 等元数据，作为不可变契约。
- 数据分区统一命名为 `train.jsonl` / `calibration.jsonl` / `development.jsonl` / `test.jsonl`，并通过 `_meta` 字段携带 source、group_id、text_sha256、stratum 等横切信息。
- 构建脚本在文件顶部用 `ROOT = Path(__file__).resolve().parents[1]; sys.path.insert(0, str(ROOT))` 注入仓库根，再 `from kev.*` 导入核心库，避免相对导入。
- 脚本使用 argparse 暴露 CLI，并在 docstring 中以 `uv run python ...` 示例命令开头，说明用途、输入输出与典型参数。
- 随机性通过 `random.Random(f"{SEED}:{seed}")` 或固定 seed 字符串派生，确保同一份源码与外部数据产生字节级可复现的 JSONL 与 manifest。
- 对外部数据集一律以 (hub_repo, commit_or_hash, path) 三元组声明，并在 manifest 的 `dataset_revisions` 中锁定 revision，保证数据溯源。
