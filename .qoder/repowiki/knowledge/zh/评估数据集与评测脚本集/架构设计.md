模块分为两层：
- `evals/<suite>/` 是只读的数据资产目录，每个子目录是一个独立评测面板（如 decision-v1/v2/v3…、transfer-v1/v2/v3…、public-pool-v4/v5/v6、breadth-v1、hard-v1、documents-v1/v2、night2、round3/4/5/6/10/15、v3–v9 等），统一由一个 `manifest.json` 描述元数据（version、seed、dataset_revisions、base_revisions、context、selection、files 的 sha256+records+questions、admission 统计、code_hashes），数据本体为 `train.jsonl` / `calibration.jsonl` / `development.jsonl` / `test.jsonl` 等 JSONL 分区。
- `scripts/` 是纯 Python 工具集合，按职责分三类：`build_*.py` 从外部源（HuggingFace Hub、GitHub、URL）下载并生成对应 `evals/<suite>` 下的 JSONL 与 manifest；`*_report.py` / `plot_*.py` / `chartstyle.py` 负责出图与报告；`calibrate_checkpoint.py`、`serving_bench.py`、`mlx_*`、`modal_retry_probe.py` 等是对已训练 checkpoint 或在线服务的运行期评测。所有脚本通过 `sys.path.insert(0, ROOT)` 导入仓库根上的 `kev.*` 包（`kev.data.materialize`、`kev.suite`、`kev.model`、`kev.api`、`kev.experiment`、`kev.composition` 等），不互相耦合，彼此独立可执行。
依赖方向单向：scripts → evals 数据 + kev 核心库；evals 自身无代码，仅含数据与清单。
