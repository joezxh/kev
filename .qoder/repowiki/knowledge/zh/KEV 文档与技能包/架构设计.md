本模块按用途分为两层：
- docs/ 是纯文档与示例资产，包含模型卡（model-cards/）、发布说明（releases/）、医疗蒸馏与生成器（medical/distill + medical/generators）及其 specs/seeds/configs 数据契约，以及顶层架构与 SFT 指南；
- skills/ 提供可由外部 Agent 框架（如 OpenAI Skills / MCP）直接加载的可执行技能，kev-deploy 通过 scripts/kev_serve.py 暴露推理服务，kev-finetune 通过 scripts/ 下的转换/生成/拆分脚本配合 references/ 的数据格式契约完成微调流水线。
两个子目录之间无代码依赖，仅通过 docs/medical/data-format.md 与 skills/kev-finetune/references/data-format.md 共享同一份数据契约；skills 中的 SKILL.md 是对外入口，docs 中的 *.md 是对内参考。
