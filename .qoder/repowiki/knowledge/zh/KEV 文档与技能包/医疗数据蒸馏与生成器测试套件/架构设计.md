两个独立测试文件分别守护两条子流水线：
- test_medical_distill.py 验证 distill 层（seed→KEV 转换、hostile teacher 合并、check_volume 容量门、EasyDistill YAML 配置），通过把 kev/console/distill 和 kev/console/generators 临时插入 sys.path 直接 import check_volume / common / make_seeds / seed_to_kev / split_data，并以 tmp_path 构造 seed.jsonl + state.jsonl 双文件契约。
- test_medical_generators.py 守护 generators 层（critical-value / medication-review / nursing-quality / triage 四个规则生成器），同样以 sys.path.insert 动态加载 gen_critical_value 等模块，并通过 run_matrix / make_goldset 校验跨尺寸运行矩阵与黄金集采样。
依赖方向单向向上：测试 → 被测脚本 → skills/kev-finetune/scripts/common & split_data；不引入任何网络或外部 LLM，全部断言基于标准库与 pytest。
