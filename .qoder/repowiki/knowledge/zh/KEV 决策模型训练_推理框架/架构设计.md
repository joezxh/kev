模块按职责切分为清晰的子层，依赖方向单向向内收敛到 `model.py` 的核心编码与推理原语：
- 协议层 `api.py`：定义 TypeSafe System One 兼容的 `Noul/Choice/Score` 请求形状及概率→答案序列化。
- 核心模型 `model.py`：实现 `encode`（state + per-question branch 打包）、`branch_mask`（块因果注意力掩码）和 `rows_of`（拆分行形式），是训练/评测/服务共享的唯一编码入口；`SERVE_MAX_STATE / MAX_TRAIN_STATE / ROW_PASS_TOKENS` 等常量统一上下文预算。
- 后端抽象：`mlx_model.py`（Apple Silicon / Qwen3.5 hybrid）与 `cuda_graphs.py`（CUDA Graph 批处理）通过 `probs_batch` 接口对接，由 `serve.py` 的 `Server` 线程池调度，支持状态前缀缓存（`PrefixCache`）与 OOM 回退。
- 训练管线 `train.py` → `full_ft.py`：LoRA 微调为主，`--full_ft 1` 走 FSDP2 bf16 全参训练；损失组合 CE/Brier/Focal/有序 KL/anchor KL/置换 KL。
- 数据与套件 `data.py` / `suite.py` / `anchors.py` / `shared_prefix.py`：公开源构建、冻结 Suite 分区、锚点分布、共享前缀优化。
- 评测与可视化 `benchmark.py` / `metrics.py` / `plot.py`：对冻结 Suite 或 JSONL 打分，输出 rows.json / report.json。
- 辅助入口 `serve.py`（FastAPI sidecar）、`publish.py`、`compare.py`、`calibrate.py`、`rounds.py`、`study_v3.py`、`transfer_v9.py`、`jev.py`、`composition.py`、`contrastive.py`、`checkpoint.py`、`device.py`、`budget.py`、`experiment.py`、`predictors.py`、`mirror.py`、`fused_qwen35.py`。
