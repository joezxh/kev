常用入口：`uv run python -m kev.serve --run runs/kev --port 8008` 启动 TypeSafe 侧车；`uv run python -m kev.train --suite evals/v7/decision-v7 --out runs/<name>` 微调；`torchrun --standalone --nproc_per_node 8 -m kev.train --full_ft 1 ...` 分布式全参训练；`uv run python -m kev.benchmark --run runs/<run>/checkpoint --suite evals/<v>/decision-<v> --out runs/<name>` 评测。环境变量控制行为：`KEV_BACKEND`、`KEV_DTYPE`、`KEV_PREFIX_CACHE`、`KEV_DATE_FACTS=1`、`KEV_TRUNCATE_STATES=1`、`KEV_API_KEY`。
