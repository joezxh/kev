- SKILL.md 使用 YAML front-matter 声明 name/description/license/compatibility/metadata，由 Modal skills 系统消费。
- 所有可执行脚本保持短小、标准库优先，并明确标注“如果用例不匹配就阅读并编辑它”，而非封装成不可改的 CLI。
- 部署与微调产物统一遵循 TypeSafe System One 协议（`POST /v1/systemone`、`GET /v1/models`），并以 `Authorization: Bearer <key>` 鉴权。
- 训练/评估结果集中写入 `runs/<run-name>/result.json`（含 `kev_ref`、`accuracy`、`brier`、`ece`、`coverage at error` 等字段）与 `errors.jsonl`，便于 `plan_size.py`、`compare` 等工具读取。
- checkpoint 通过 Hugging Face Hub ID（如 `jaredpalmer/kev-4b`）引用，部署时通过 `KEV_MODEL` / `--init-from` 选择，避免硬编码路径。
