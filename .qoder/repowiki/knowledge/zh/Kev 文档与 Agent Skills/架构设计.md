模块按用途分为两层：
- `docs/`：静态发布资产。`model-cards/` 下每个 `.md` 对应一个 Kev 变体（0.8b / 4b / 9b / 27b 及 Qwen3 后缀），`releases/kev-1.0-assets.json` 是发布清单，`kev-family-summary.json` 汇总各变体的 transfer_acc、transfer_brier 与任务级指标，供外部工具渲染。
- `skills/`：Agent 可消费的 SKILL.md 包，遵循 Modal skills 约定（YAML front-matter 含 name/description/license/compatibility/metadata）。
  - `skills/kev-deploy/`：单文件部署技能，入口 `scripts/kev_serve.py` 是一个自包含 Modal app，暴露 TypeSafe System One 协议（`POST /v1/systemone`、`GET /v1/models`），通过 `modal deploy` 把 Kev checkpoint 以 bf16 形式托管到零扩缩 GPU。
  - `skills/kev-finetune/`：端到端微调流水线，`scripts/` 下六个短脚本分别承担 workload 提取、CSV/JSONL 转换、OpenAI 兼容 API 合成数据、样本量规划、训练/校准/开发集划分；`scripts/kev_modal.py` 是唯一的 Modal app，暴露 `validate/train/evaluate/compare/pull/publish/teardown/Serve` 子命令，所有训练产物落 `runs/<run-name>/`。
依赖方向单向：SKILL.md 驱动用户运行 scripts → scripts 调用 Kev 包与 Modal；docs 不参与运行时。
