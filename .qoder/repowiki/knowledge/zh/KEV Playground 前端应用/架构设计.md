采用 Next.js App Router 的分层结构：
- `src/app` 为路由入口，`page.tsx`/`layout.tsx` 定义根布局、`/chess` 国际象棋演示、`/console/*` 控制台子应用（datasets/deploy/eval/images/train/jobs）、`/docs/[lang]` 多语言文档。
- `src/app/api` 是薄代理层：`[...path]/route.ts` 将 `/kev/console/api/**` 转发到上游 FastAPI 服务，并逐块透传 SSE (`text/event-stream`)，同时透传 `Last-Event-ID` 以支持断点续传；`/api/docs/route.ts` 暴露文档接口。
- `next.config.ts` 通过 `rewrites` 把 `/kev/:path*` 重写到 `KEV_API`（默认 `http://127.0.0.1:8008`），并以 `output: 'standalone'` 输出独立可部署产物。
- `src/lib` 存放纯逻辑：`kev.ts` 定义 SystemOne 请求/响应类型及 `PRESETS` 示例数据，并通过 `fetch('/kev...')` 调用后端；`i18n.tsx` 提供 `LanguageProvider`/`useLang` 双语文境；`console.ts`、`docs.ts`、`chess.ts`、`utils.ts` 分别承载对应页面逻辑。
- `src/components/ui` 是基于 shadcn/base-ui 的原子组件库，`src/components/console` 为控制台专用图表与监控组件（LossChart/CoverageCurve/ReliabilityDiagram/JobMonitor 等），`playground.tsx` 是主交互入口，组合 Preset 选择、JSON 编辑器、答案卡片与 Permute 分析表。
依赖方向：UI 组件 → lib 类型/工具 → API 代理 → 外部 FastAPI 服务，浏览器侧不持有密钥（`NEXT_PUBLIC_KEV_API_KEY` 仅作为空兜底）。
