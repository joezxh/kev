- 每个评测 suite 在 `evals/<name>/manifest.json` 中用 `sha256` + `records` + `questions` 锁定每个 `.jsonl` 分区的字节级指纹，禁止运行时重新生成。
- 外部数据源通过 `pins.hf` / `pins.url` + `sha256` + `code` commit hash 三重固定，并在 `dataset_revisions` / `base_revisions` 中记录 HuggingFace repo 的精确提交。
- 构建脚本统一采用 `argparse` + 顶层 `main()` 模式，并以 `uv run python scripts/<name>.py` 方式调用，避免隐式依赖。
- 发布产物必须满足可复现性：tarball 成员排序、uid/gid=0、mtime=`SOURCE_DATE_EPOCH`（或 release_date 午夜 UTC），并输出 `SHA256SUMS.txt`。
- Docker 相关脚本（`docker-entrypoint.sh`、`health-check.sh`）统一使用 `${VAR:-default}` 风格的环境变量注入，并通过 `set -e` 保证失败即退出。
