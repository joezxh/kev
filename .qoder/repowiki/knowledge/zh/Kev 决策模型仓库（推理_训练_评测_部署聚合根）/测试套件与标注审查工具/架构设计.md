本模块由两部分组成：
- `tests/`：按子系统划分的 pytest 用例集合，覆盖 API 契约（`test_api.py`）、FastAPI 控制台 HTTP 面（`test_console_*.py`）、持久化状态机（`test_console_db.py`）、模型/训练/数据管线（`test_unit.py`, `test_model.py`, `test_research.py`, `test_rounds.py`, `test_generators.py` 等）以及 MLX 后端（`test_mlx.py`）。HTTP 类用例通过 FastAPI `TestClient` 直接挂载 `create_app(store=Store(...))` 运行，不启动真实进程；需要外部服务的用例（如 `test_api.py`）使用 `pytest.mark.server` 标记并通过 `KEV_BASE_URL` 环境变量连接已运行的服务器。
- `tools/review/`：独立的 Vite + React 19 + TypeScript 单页应用，用于人工审核 AI 提议的标签，所有决策仅落 `localStorage`，支持键盘导航、撤销、过滤与导出 `reviews.jsonl`。
依赖方向单向指向被测试的 `kev.*` 包，测试之间无相互依赖。
