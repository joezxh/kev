本模块由 docs/ 与 skills/ 两个并列子树组成：docs/ 提供纯静态知识（learn、knowledge、medical、model-cards、releases、research、studio-preview、superpowers），skills/ 提供可被 Agent 调用的可执行 Skill（kev-deploy、kev-finetune）。两者通过 SKILL.md + README.md 的双入口契约对外暴露——SKILL.md 描述能力与参数，README.md 提供人类可读说明；scripts/ 下的 Python 脚本是技能的实现主体，引用 docs/ 中的 data-format.md、runbook*.md 等规范文件作为输入输出契约。该目录本身不含运行时代码，仅承担文档与可复用技能包的版本化发布职责。
