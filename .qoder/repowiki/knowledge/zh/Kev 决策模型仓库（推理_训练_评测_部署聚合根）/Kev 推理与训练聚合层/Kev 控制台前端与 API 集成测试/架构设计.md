模块由三部分组成，依赖方向单向：前端 → `/api/console` 同源代理 → 后端 `kev.console`。
- `playground/src/lib/console.ts`：浏览器端 API 客户端，所有请求统一经 `call<T>()` 走 `/api/console/*` 代理；集中导出 Job/Metric/Gate/Artifact/ScenarioDomain/Project/Member/Quota/Webhook/Invoice 等 TS 类型，错误统一包装为 `ApiError(detail)` 并按 kind 分派（validation/conflict/gate/upstream/executor），并提供基于 `EventSource` 的 SSE 日志订阅（`streamJob` + `subscribeStream`，断线重连依赖 Last-Event-ID header 续传而非 URL after_id）。
- `playground/src/components/ui/*.tsx`：基于 `@base-ui/react` 与 `class-variance-authority` 的原子 UI 组件（alert/dialog/dropdown-menu/progress/scroll-area/select/skeleton/sonner/table/tooltip），作为 shadcn/ui 风格的构建块被上层页面消费。
- `tests/test_console_api.py`：使用 FastAPI `TestClient` 直接挂载 `create_app(store=Store(...))`，以临时 SQLite 驱动覆盖 config/scenarios/jobs/preview/submit/cancel/retry/events/stream/artifacts/gates/endpoints 等端点，并通过 `monkeypatch.setattr` 替换 `evaluate`、`artifacts.register` 等内部函数模拟闸门与产物注册，不启动真实 executor。
