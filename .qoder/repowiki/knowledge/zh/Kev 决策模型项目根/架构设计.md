根目录以 `kev/` Python 包为唯一可执行核心，其他子模块围绕它形成上下游：
- 数据侧：`evals/` 提供冻结的 decision/transfer/breadth/documents/longdoc/hard/night2 等评测集，由 `scripts/` 中的构建脚本生成并产出 `manifest.json`。
- 训练侧：`experiments/*.json` 声明超参，`modal_app.py` + `skills/` 通过 Modal Skill 触发 `kev/train.py`，结果落盘到 `runs/<experiment>/<trial>/`（provenance.json/result.json/train.log）。
- 评估侧：`kev/evaluate.py` 读取同一份 eval manifest 对 checkpoint 跑分，输出 `report.json` 与 `rows.json`，再由 `scripts/*_report.py` 汇总成 `runs/leaderboard.jsonl`。
- 部署侧：`deploy/` 与 `deploy_scripts/` 消费已发布的 HuggingFace checkpoint，`playground/` 通过 Next.js 前端调用 `space/app.py` 暴露的 REST API。
- 根级入口 `modal_app.py`、`pyproject.toml`、`.github/workflows/ci.yml` 是跨子模块的统一装配点：CI 同时运行 `tests/`、校验 eval manifest、构建 Docker 镜像并发布到 HuggingFace。
