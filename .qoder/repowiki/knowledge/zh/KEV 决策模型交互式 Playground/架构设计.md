采用 Next.js 16 App Router 结构：
- `src/app` 为路由层，`layout.tsx` 通过 `LanguageProvider` 注入全局语言上下文；`page.tsx` 渲染主 Playground，`chess/page.tsx` 渲染国际象棋演示，`docs/[lang]/page.tsx` 渲染多语言文档。
- `src/components/ui` 由 shadcn 生成的原子 UI 组件（button/tabs/card 等），业务组件 `playground.tsx`、`answer-card.tsx`、`chess-game.tsx`、`chess-board.tsx` 组合出交互界面。
- `src/lib` 为纯逻辑层：`kev.ts` 定义与 `/v1/systemone` 契约对齐的类型（Question/Answer/SystemOneRequest/PermuteResponse）并提供 `api` 客户端（systemOne/separate/permute/models），同时内嵌 `PRESETS` 示例集；`i18n.tsx` 提供 `LanguageProvider` + `useLang()` 上下文，键空间以 `kev.*` / `chess.*` 命名空间区分页面；`chess.ts` 封装 chess.js 走法生成，`docs.ts` 加载 Markdown 文档，`utils.ts` 提供通用工具。
- 依赖方向单向：app → components → lib，lib 不反向引用任何 UI 或路由。
