本模块由两块互不依赖的内容组成：
- `docs/`：纯文档与资源。`model-cards/` 按尺寸（0.8B/4B/9B/27B）维护中英文模型卡；`releases/` 维护发布清单；`medical/` 是独立方案包，通过 `specs/*.json`（5 个场景 workload spec）+ `generators/`（阈值表 + 规则引擎 + `run_matrix.py` 编排器）驱动数据生成、划分、训练、对比与部署，并通过 `data-format.md` / `runbook.md` 串联执行流程。
- `skills/`：遵循 Modal Skills 规范的两个 skill，每个以 `SKILL.md` 为入口，附带 `scripts/` 可执行脚本与 `references/` 参考文档。`kev-deploy/` 提供单文件 `scripts/kev_serve.py` 作为自包含 Modal app；`kev-finetune/` 提供 `extract_workload.py → convert_data.py → generate_data.py → plan_size.py → split_data.py → kev_modal.py` 的流水线，并以 `assets/workload.example.json` 作为 workload schema 示例。
依赖方向单向：`docs/medical/generators/` 仅消费 `specs/` 与外部 `skills/kev-finetune/scripts/`，不反向修改 skill 源码（README 明确禁止改动 `skills/`）。
