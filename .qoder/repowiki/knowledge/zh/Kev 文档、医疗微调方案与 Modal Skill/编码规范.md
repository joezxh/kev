- Skill 入口统一使用 YAML front matter（`name`/`description`/`license`/`compatibility`/`metadata.author`/`version`/`repository`），便于 Modal skills 索引。
- 所有用户可见文档均提供 `_CN.md` 中文镜像，英文主文档通过 badge 链接到对应中文版。
- 工作负载描述采用 JSON Schema 风格：`workload.json` 字段（`domain`/`state`/`state_example`/`questions`/`guidance`/`variety`）在 `generate_data.py`、`convert_data.py`、`split_data.py` 间共享。
- 多语言/多尺寸配置通过命令行参数（`--sizes 8b,4b`、`--init-from`、`--gpu`、`KEV_*` 环境变量）而非代码分支切换，保持单一实现路径。
