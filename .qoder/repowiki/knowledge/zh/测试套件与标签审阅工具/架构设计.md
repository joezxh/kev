模块由两个独立子域组成：
- `tests/`：以 pytest 组织的多层测试集。`test_unit.py` 覆盖无权重场景（API 映射、置信度公式、mask、token 清洗）；`test_model.py` 依赖真实 checkpoint (`runs/smoke-hl/00-trial-0/checkpoint`) 和 Qwen 基座做数值等价性断言；`test_api.py` 通过 httpx 对接运行中的 `/v1/systemone` 服务端，并可选地用 `typesafe_sdk` 校验 SDK 契约；其余文件按能力维度拆分（breadth/hard/longdoc/research/generators/rounds/skill_scripts/documents_tools/conventions）。测试通过 `pytest.mark.server` 标记与 `KEV_BASE_URL` 环境变量区分需启动服务的用例。
- `tools/review/`：独立的 Vite + React 19 + TypeScript SPA，仅依赖 `react`/`react-dom`，通过 `localStorage` 持久化审阅结果，从 `public/sample.jsonl` 或用户拖入的 `.jsonl` 读取数据，导出 `reviews.jsonl`。该子应用不依赖后端，构建产物仅供本地预览。
依赖方向单向：tests → `kev.*` 内部模块；tools/review 完全自包含，与 Python 代码无耦合。
