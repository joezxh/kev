- 所有面向后端的类型（Question、Answer、SystemOneRequest/Response、PermuteResponse）在 `lib/kev.ts` 中集中声明并与后端 `/v1/systemone` 契约一一对应，组件仅消费这些类型而不重复定义。
- 组件文件顶部统一以 `'use client';` 指令标记客户端组件，服务端布局与页面则不添加该指令。
- 异步 API 调用统一通过 `run(label, fn, done)` 包装器处理 busy/error 状态，避免在各按钮回调中重复编写 try/catch 与 loading 切换。
- UI 样式全部使用 Tailwind 原子类，颜色语义化使用 `text-muted-foreground`、`bg-card`、`border-border` 等设计 token，而非硬编码色值。
- 可复用的展示面板（如 `DistributionPanel`）以 props 驱动渲染，保持固定高度以避免布局抖动。
