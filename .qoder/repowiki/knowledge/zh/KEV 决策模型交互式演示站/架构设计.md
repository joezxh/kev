采用 Next.js App Router 的单页应用结构：`src/app/layout.tsx` 提供全局字体与元信息；`src/app/page.tsx` 渲染主 Playground（输入 state + questions，调用 `/v1/systemone`），`src/app/chess/page.tsx` 渲染国际象棋对弈页面。UI 层由 `src/components/` 下的 React 组件构成，其中 `playground.tsx`、`chess-game.tsx` 是业务入口，`answer-card.tsx`、`chess-board.tsx` 为领域子组件，`components/ui/` 通过 shadcn 提供的原子 UI 组件（button、tabs、switch 等）组合而成。状态与网络层集中在 `src/lib/`：`kev.ts` 定义与后端 `/v1/systemone`、`/v1/systemone/separate`、`/v1/systemone/permute`、`/kev/v1/models` 对齐的类型契约（Question/Answer/SystemOneRequest/Response/PermuteResponse）并提供 `api` 客户端；`chess.ts` 封装 chess.js 逻辑与模型交互；`kev.ts` 还内嵌一组 `PRESETS` 测试用例。构建配置位于根目录的 `next.config.ts`、`tsconfig.json`、`eslint.config.mjs`、`postcss.config.mjs`，并通过 `components.json` 驱动 shadcn 组件生成。此外 `scripts/jev-evaluate.mjs` 是一个独立的 Node CLI，使用 `ai` 包的 `experimental_evaluate` 直接评测 `typesafe-ai/jev` 模型，作为前端之外的离线评估工具。
