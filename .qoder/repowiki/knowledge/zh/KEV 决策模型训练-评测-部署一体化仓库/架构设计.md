顶层通过 `modal_app.py` 把 `kev.experiment.execute_trial` / `continue_trial` 等核心流水线以 Modal Function 形式调度到 GPU 容器，共享 `runs/`（Modal Volume）作为所有子模块产出的统一数据总线：
- `experiments/*.json` 定义每轮 study 的 trial 配置，被 `modal_app.admit_study` 校验预算后下发；
- `evals/*` 冻结数据集由 `scripts/build_*.py` 生成，被 `kev.benchmark` / `run_locked_test` 消费；
- `runs/<study>/<trial>/` 产出 `provenance.json` + `result.json` + `report.json`，被 `kev.rounds`、`modal_app::benchmarks`、`modal_app::release_*` 读取；
- `kevserve` / `playground` 通过 TypeSafe `/v1/systemone` API 访问同一份 checkpoint；
- `deploy`、`deploy_scripts`、`space/` 提供 Docker Compose 与 WSL2 一键启动入口，复用 `kev.serve`。
跨子模块的契约集中在 `kev/api.py`（TypeSafe schema）、`kev/suite.py`（manifest/jsonl 格式）和 `kev/experiment.py`（provenance/result 结构），所有训练、评测、发布脚本都围绕这三个文件读写。
