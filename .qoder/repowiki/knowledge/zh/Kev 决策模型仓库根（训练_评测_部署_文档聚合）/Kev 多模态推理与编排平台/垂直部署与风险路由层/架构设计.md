模块以纯决策层形式存在，不持有权重或 CUDA 状态，依赖 `kev.checkpoint` 加载适配器与元数据，由上层 `kev.serve.Server` 驱动推理。

- 领域建模：`Adapter`（一个行业在某个 size 上的 delta + 校准温度/阈值）、`Scenario`（含 `risk`、`human_review`、`escalation_cutoff`）、`Industry`（场景+适配器集合）、`IndustryRegistry`（可 JSON 序列化/反序列化的部署清单），以及内置的 `_medical/_finance/_legal/_education/_support` 五个行业工厂函数。
- 路由层：`Router.plan` 仅读注册表决定初始 size（受 `RISK_FLOOR` 约束），`Router.decide` 在已有小模型置信度上应用 `cutoff` 决定是否升级到 `LARGE`；所有决策通过 `Decision` 记录 `reason`（`REASON_*` 常量）以便审计。
- 阈值来源：`ThresholdBook.from_results` 从训练产出的 `result.json` 中抽取 `selective["0.8"].confidence_cutoff`，拒绝缺失选择性预测块的条目，确保阈值永远来自测量而非常量。
- 适配器池：`AdapterPool` 包装一个未合并的 PeftModel，通过 `set_adapter` 切换行业 delta 并替换指针头，同一 backbone 下零重算；通过 `IndustryRegistry.families` 校验 base/head_dim/lora rank 一致性，冲突时抛 `AdapterConflict`。
- 默认入口：通过 PEP 562 的 `__getattr__` 懒暴露 `INDUSTRIES`，首次访问才构建内置五行业，导入无副作用。
- 测试覆盖：`tests/test_vertical.py` 用真实 peft Llama 构造 tiny model 验证 pool 行为，其余用例全部无 GPU，只断言规则不变量。
