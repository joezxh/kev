- 每个 Skill 以 YAML front-matter 开头的 `SKILL.md` 声明 name/description/license/compatibility/metadata，供 Agent 解析能力元信息。
- 所有用户可见文档均提供 `_CN.md` 中文镜像版本，英文与中文内容一一对应。
- Python 脚本保持短小且自包含，注释说明其用途是“被阅读和编辑而非绕过”，参数通过命令行与 `KEV_*` 环境变量注入。
- 部署类脚本统一通过 `Authorization: Bearer <key>` 头进行鉴权，未携带 key 的请求返回 401。
- 模型与端点命名采用不可变版本语义（如 `--name x-v1`、`KEV_APP_NAME=kev-9b`），重试需递增版本号。
