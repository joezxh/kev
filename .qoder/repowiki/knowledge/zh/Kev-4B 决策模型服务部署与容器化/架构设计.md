本模块是纯部署侧的叶子模块，不包含业务代码，围绕三个层次组织：
- 镜像层：`Dockerfile` 基于 `python:3.13-slim-bookworm`，单阶段构建直接 pip 安装 fastapi/uvicorn/torch/transformers/peft/accelerate/datasets/pydantic，并通过 `git clone --depth 1` 拉取轻量源码仓库，ENTRYPOINT 以 `python -m kev.serve` 启动 FastAPI 服务，暴露 8008 端口并内置 HEALTHCHECK。
- 编排层：`docker-compose.yml` 定义两个 service —— `kev-server`（production target，固定 CUDA 12.1 + cuDNN 8，挂载 `kev-model-cache`、`kev-prefix-cache` 卷，启用 nvidia runtime 和 GPU reservation）与 `kev-dev`（dev target，源码目录 `-rw` 挂载用于热重载），共用自定义 bridge 网络 `kev-network`。
- 自动化层：`deploy.sh`（Linux/macOS）与 `deploy-windows.ps1`（Windows PowerShell 兼容版）封装完整的 build → run → health-check → API smoke-test 流程，支持 `deploy/status/stop/restart/logs/clean` 子命令；`.dockerignore` 排除 `.git`、`venv`、`tests`、`runs/checkpoints/data`、`node_modules` 等无关内容以缩小构建上下文。
依赖方向单向向外：脚本调用 docker/docker-compose，compose 引用 Dockerfile，文档文件仅作为说明不参与构建。
