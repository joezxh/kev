kev 包以 `model.py`（Checkpoint / LoadOptions / tokenizer 加载）和 `api.py`（SystemOneRequest/Response Pydantic 契约）为共享边界：`serve.py` 通过 FastAPI 暴露 `/v1/systemone`，复用 `api.to_record`/`to_answers` 把请求编码成内部 record 并回写 TypeSafe 兼容答案；`study_v3.py`、`suite.py`、`composition.py`、`contrastive.py`、`data.py` 共同构成合成数据生成与 split 管理管线，产出带 manifest 的训练集；`vertical.py` 在运行时按风险等级选择 LoRA 适配器并通过 AdapterPool 共享骨干；`console/` 子模块是独立的前端 + pytest 集成测试，仅依赖 `api` 与 `serve` 暴露的 HTTP 契约。所有子模块围绕「state → questions → probabilities」这一单指针原语对齐，不直接互相调用业务逻辑。
