模块由三部分组成：
- `playground/src/lib/console.ts`：浏览器端 API 客户端，统一通过同源代理 `/api/console/*` 访问后端，定义 Job/Metric/Gate/Artifact 等类型、`ApiError` 异常类（按 kind 分派 validation/conflict/gate），并提供 REST 调用与基于 EventSource 的 SSE 日志流订阅（`streamJob` + `subscribeStream`）。
- `playground/src/components/ui/*.tsx`：基于 `@base-ui/react` 与 `class-variance-authority` 的原子 UI 组件（alert/dialog/dropdown-menu/progress/scroll-area/select/skeleton/sonner/table/tooltip），作为 shadcn/ui 风格的构建块被上层页面消费。
- `tests/test_console_api.py`：使用 FastAPI `TestClient` 直接挂载 `kev.console.app.create_app`，以内存 SQLite (`Store`) 驱动，覆盖 config/scenarios/jobs/preview/submit/cancel/retry/events/stream/artifacts/gates/endpoints 等端点，并验证凭据不泄露、闸门失败 422、断线重连 Last-Event-ID 续传、崩溃恢复将残留 running 置 interrupted 等关键行为。
依赖方向：前端 → `/api/console` 代理 → 后端 `kev.console`；测试直接 import 后端实现，不经过 HTTP 代理。
