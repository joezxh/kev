- UI 组件统一使用 `data-slot="*"` 属性标记语义槽位，并通过 `cn()` 合并 className，便于外部样式定位。
- REST 客户端集中封装在 `playground/src/lib/console.ts` 的 `call<T>()` 中，所有接口以 `api.*` 命名空间导出，错误统一包装为 `ApiError(detail)`。
- SSE 事件处理对每个 event type 单独绑定监听器并显式 `JSON.parse` 到具体 TS 类型，避免泛型推导丢失字段信息。
- 测试用例通过 `monkeypatch.setattr` 替换 `kev.console.app.evaluate`、`artifacts.register` 等内部函数来模拟闸门与产物注册，而非启动真实 executor。
